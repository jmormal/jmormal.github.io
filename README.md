# jmormal.github.io

Landing pages for **Unison Mesh**, an offline phone-to-phone speaker app.

- `/unison/j#…` — the page a Unison Mesh QR code opens when the app isn't installed yet.
  The invite code after `#` stays in the browser: it is never sent to this server.
- `/.well-known/assetlinks.json` — lets Android open those links directly in the app.

No analytics, cookies or external resources.
